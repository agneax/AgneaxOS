## ⚡ Get Started in 3 Steps

### 1. Download & Verify ISO
Download the official release ISO and verify its cryptographic SHA-256 integrity:

```bash
# Linux / macOS Terminal
sha256sum AgneaX-OS-amd64.iso

# Windows PowerShell
Get-FileHash -Algorithm SHA256 .\AgneaX-OS-amd64.iso
```

### 2. Flash to USB Media
Flash the ISO onto an 8GB+ USB flash drive using your tool of choice:
- **Rufus:** Select ISO → Partition scheme: **GPT** (UEFI) or **MBR** (BIOS) → Write in ISO mode.
- **Ventoy:** Install Ventoy to USB → Copy `AgneaX-OS-amd64.iso` directly to the drive.
- **Balena Etcher:** Select ISO → Select USB → Flash.

### 3. Boot & Experience
Restart your computer, press your motherboard boot menu key (`F12`, `F9`, `F11`, or `Esc`), and select your USB drive:
- **Live Desktop:** Test Wi-Fi, audio, and all native apps in memory without modifying your hard drive.
- **Install AgneaX OS:** Click the desktop installer whenever you're ready for permanent deployment or safe dual-boot alongside Windows.
